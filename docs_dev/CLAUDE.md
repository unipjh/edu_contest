작업 전 반드시 이 파일 전체를 읽는다.
판단이 필요할 때마다 여기로 돌아온다.

---

## 프로젝트 한 줄 정의

학생이 PDF를 올리면 NCIC 교육과정 공공데이터와 연결해
이해→점검→복습이 단절 없이 이어지는 AI 학습도우미.

## 핵심 철학 (모든 구현의 기준)

> AI가 먼저 답을 주는 서비스가 아니라,
> 사용자가 먼저 생각하고 AI가 보조하는 서비스.

채팅 응답, 퀴즈 순서, UI 흐름 어디서든 이 원칙을 위반하지 않는다.

---

## 작업 규칙

1. **작업 전**: 해당 기능의 `docs/` 문서를 먼저 읽는다
2. **순서**: A → B → C → D → E. 앞 단계 완성 전 다음 단계 시작 금지
3. **스키마**: Firestore 스키마 임의 변경 금지. 변경 필요 시 `docs/SCHEMA.md` 먼저 수정
4. **Gemini 호출**: 반드시 `src/lib/gemini.js`에서만. 컴포넌트 직접 호출 금지
5. **리팩터링**: 기능 구현 중 전체 리팩터링 금지

## 기능 완료 기준 (5가지 모두 통과해야 "완료")

```
[ ] 정상 경로가 처음부터 끝까지 동작한다
[ ] API 호출 중 로딩 상태가 표시된다
[ ] API 실패 시 앱이 크래시하지 않고 안내 메시지가 표시된다
[ ] 데이터 없을 때 빈 화면이 아닌 안내 텍스트가 표시된다
[ ] 새로고침 후에도 Firestore 데이터가 유지된다
```
