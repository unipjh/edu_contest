## 해결하는 문제 3가지

### S2. AI가 학생의 이해를 대체한다
학생의 67.9%가 생성형 AI를 사용하지만, AI 답변 신뢰도 만족은 3.32/5점.
믿지 못하면서도 의존하는 구조. AI가 답을 주면 학생이 생각을 멈춘다.
→ **Co-study 해결**: 학습목표 제안 → 읽기 → 퀴즈 → AI 보조 순서 설계

### S3. 교육 공공데이터가 학습자료와 연결되지 않는다
한국 학생 디지털 접근성 OECD 1위, 수업 중 공공자료 활용도 최하위(-0.279).
NCIC 성취기준 DB, 에듀넷 학습자료가 존재하지만 학생 자료와 연결되지 않는다.
→ **Co-study 해결**: 업로드 즉시 NCIC 성취기준 자동 매핑

### S4. 학습 흐름이 단절된다
KERIS 연구: 평가 후반부 포기율 초반 대비 2배 이상 증가.
막혔을 때 "내가 어디서 막혔는지" 알 수 없어 흐름이 끊긴다.
→ **Co-study 해결**: 성취기준 단위 학습 상태 대시보드
