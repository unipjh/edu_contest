# Co-Study — AI 기반 학습 도우미

PDF 학습자료를 업로드하면 교육과정 성취기준을 자동으로 연결하고,  
AI 채팅·퀴즈·하이라이트·학습 분석까지 한 화면에서 제공하는 학습 보조 웹앱입니다.

---

## 배포 URL

**→ [https://edu-contest.vercel.app](https://edu-contest.vercel.app)**

---

## 샘플로 바로 테스트하기

이 저장소에 **생성형 AI로 제작된 2022 개정 교육과정 기반 수학 학습 자료** 샘플이 포함되어 있습니다.

### 순서

| 단계 | 행동 |
|------|------|
| 1 | 이 저장소에서 **[`co-study-2022-math-demo.pdf`](co-study-2022-math-demo.pdf)** 다운로드 |
| 2 | 위 배포 URL 접속 → **라이브러리** 탭 |
| 3 | **업로드** 버튼 → 다운로드한 PDF 선택 |
| 4 | AI가 성취기준 매핑·학습목표 생성 (약 10~20초) |
| 5 | 문서 카드 클릭 → **뷰어** 진입 |

### 뷰어에서 해볼 것들

- **Chat** — 모르는 문제나 개념을 질문하면 AI가 현재 페이지 맥락으로 설명
- **Quiz** — 현재 페이지 또는 전체 문서 범위로 객관식 문제 자동 생성
- **하이라이트** — 텍스트 드래그 → 색상 선택으로 메모 저장, Chat으로 바로 전송
- **O/X 잠금** (`잠금 ON`) — 다음 페이지로 넘기기 전 AI가 이해 확인 질문 출제
- **학습목표** — 상단 배너에서 이 자료의 학습목표 3개 확인

## AI 기능 아키텍처

### 모듈 구성

| 모듈 | 역할 |
|------|------|
| `pdfText` | pdfjs-dist 기반 페이지별 텍스트 추출 |
| `ncicMapper` | 키워드 → NCIC 성취기준 오프라인 매핑 (형태소 정규화 + 부분 문자열 스코어링) |
| `gemini` | Gemini 2.0 Flash API 인터페이스 — 모든 AI 호출의 단일 진입점 |
| `useDocumentUpload` | 업로드 파이프라인 오케스트레이터 (텍스트 추출 → 매핑 → 목표 생성 → Firestore 저장) |
| `useChatMessages` | 채팅 세션 관리 — 대화 기록 유지 및 Firestore 동기화 |
| `useQuizHistory` | 퀴즈 기록 저장·조회, 오답 여부 판정 |
| `useLearningDashboard` | 성취기준별 학습 현황 집계, 학습 요소 분석 실행 |

### 업로드 파이프라인 (1회, 비동기 순차 실행)

```
PDF 파일 선택
  │
  ├─ [pdfText 모듈]
  │    pdfjs-dist로 페이지 순서대로 텍스트 추출
  │    → pageTexts[], pageCount
  │
  ├─ [gemini 모듈] 키워드 추출
  │    입력: 앞 5페이지 텍스트 합산 (최대 4,000자)
  │    프롬프트 틀:
  │      "교육과정 관련 핵심 키워드를 5~15개 추출해줘.
  │       단원명·챕터 제목과 핵심 교과 개념 모두 포함.
  │       JSON 배열로만 답해."
  │    출력: ["키워드1", "키워드2", ...] (최대 15개)
  │
  ├─ [ncicMapper 모듈] 성취기준 오프라인 매핑
  │    키워드 → 형태소 정규화 → NCIC DB 부분 문자열 매칭
  │    → standards[] (성취기준 코드), standardTargets[] (이해 단위)
  │    ※ 네트워크 없이 로컬 JSON만 사용
  │
  ├─ [gemini 모듈] 학습목표 생성
  │    입력: 첫 페이지 텍스트 (최대 2,000자) + standards + standardTargets
  │    프롬프트 틀:
  │      "성취기준: {codes}
  │       매핑된 이해 단위: [{code} {title}: {description}, ...]
  │       자료: {첫 페이지 텍스트}
  │       → 학생이 읽기 전 확인할 학습목표 3개.
  │         짧고 관찰 가능한 행동 문장, JSON 배열로 출력."
  │    출력: ["목표1", "목표2", "목표3"]
  │
  └─ Firestore 저장
       documents/{docId}: pageTexts, pageCount,
                          standards, standardTargets,
                          subject, grade, unit,
                          learningGoals, storageUrl
```

### 뷰어 AI 모듈 — 기능별 프롬프트 구조

#### O/X 페이지 잠금

페이지 이동 시 현재 페이지 이해를 확인하고, 정답이어야 잠금 해제.

```
입력: 현재 페이지 텍스트 (최대 2,200자) + 성취기준 코드
프롬프트 틀:
  "{n}페이지를 읽었는지 확인하는 O/X 사실 질문 1개.
   정답은 true/false. 단순 암기보다 핵심 이해 확인.
   JSON 객체로만 답해:
   { statement, answer: bool, explanation }"
출력: { statement: string, answer: boolean, explanation: string }
```

#### 소크라테스식 Chat

매 턴마다 대화 기록 전체를 컨텍스트에 포함. 성취기준·공공 학습자료 URL도 주입.

```
시스템 역할: "한국 고등학생을 돕는 학습 보조 AI"

컨텍스트 블록 (매 요청마다 재구성):
  성취기준: [{code} {subject} {grade} | 단원: {unit} | 목표: {description}
             | 공식 자료: {에듀넷 URL} | 공공 학습자료: {title + URL}, ...]
  이해 단위: [{code} {title}: {description}, ...]
  현재 페이지: {n}
  [선택 텍스트: "{하이라이트된 내용}"]   ← 드래그 → Chat 전송 시만 포함
  [페이지 내용: {현재 페이지 텍스트 최대 1,600자}]

응답 형식 지시:
  "핵심 설명: 개념을 짧게
   맥락: 현재 페이지나 선택 맥락과 연결 (페이지 문장 인용)
   생각해볼 질문: 꼬리 질문 1개
   출처: [성취기준 코드] 이해 단위 / 공식 자료 URL"

입력: 대화 기록 전체 (role: user/assistant)
출력: 형식화된 텍스트 응답
```

#### Quiz 생성

페이지 단위(1문항)와 전체 문서 단위(세트, 최대 10문항) 두 모드로 동작.

```
입력 (페이지):   현재 페이지 텍스트 (최대 4,200자) + 성취기준 코드
입력 (전체):     전 페이지 텍스트 합산 (최대 7,000자) + 성취기준 코드
프롬프트 틀:
  "다음 학습 자료 범위({현재 페이지 | 전체 문서})에서
   객관식 문항 {1 | N}개 생성. 단순 암기보다 핵심 개념 이해 확인.
   JSON 객체(또는 배열)로만 출력:
   { question, options[4], answer: index, standard_code, explanation }"
출력: 단일 객체 또는 배열 (최대 10개 슬라이스)
```

### 대시보드 분석 (수동 실행)

사용자가 "학습 요소 분석" 버튼을 누를 때 한 번 실행.  
퀴즈·채팅·메모 기록을 텍스트 요약으로 직렬화한 후 단일 프롬프트로 전달.

```
입력:
  퀴즈 오답 및 시도 기록 (문제·정오 여부·성취기준 코드)
  채팅 질문 기록 (학생 발화만 추출)
  메모/하이라이트 기록 (텍스트 내용)

프롬프트 틀:
  "학생의 학습 기록을 분석해서 핵심 학습 요소를 JSON으로 추출해줘.
   퀴즈 오답 기록: {summary}
   채팅 질문 기록: {summary}
   메모/하이라이트: {summary}
   JSON 형식:
   {
     concepts: [학습한 교과 개념 5~8개],
     weakPoints: [오답·반복 질문 기반 보완점 1~3개],
     strongPoints: [정답·메모 많은 이해 항목 1~3개]
   }"

출력: 대시보드 profileCard에 표시
```
