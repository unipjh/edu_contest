# Co-Study — AI 기반 학습 도우미

PDF 학습자료를 업로드하면 교육과정 성취기준을 자동으로 연결하고,  
AI 채팅·퀴즈·하이라이트·학습 분석까지 한 화면에서 제공하는 학습 보조 웹앱입니다.

---

## 배포 URL

**→ [https://edu-contest.vercel.app](https://edu-contest.vercel.app)**

---

## 샘플로 바로 테스트하기

이 저장소에 **2022학년도 수능 수학** 문제지 샘플이 포함되어 있습니다.

### 순서

| 단계 | 행동 |
|------|------|
| 1 | 이 저장소에서 **[`co-study-2022-math-demo.pdf`](co-study-2022-math-demo.pdf)** 다운로드 |
| 2 | 위 배포 URL 접속 → **라이브러리** 탭 |
| 3 | **업로드** 버튼 → 다운로드한 PDF 선택 |
| 4 | AI가 성취기준 매핑·학습목표 생성 (약 10~20초) |
| 5 | 문서 카드 클릭 → **뷰어** 진입 |

### 뷰어에서 해볼 것들

- **Chat** — 모르는 문제나 개념을 질문하면 AI가 현재 페이지 맥락으로 설명
- **Quiz** — 현재 페이지 또는 전체 문서 범위로 객관식 문제 자동 생성
- **하이라이트** — 텍스트 드래그 → 색상 선택으로 메모 저장, Chat으로 바로 전송
- **O/X 잠금** (`잠금 ON`) — 다음 페이지로 넘기기 전 AI가 이해 확인 질문 출제
- **학습목표** — 상단 배너에서 이 자료의 학습목표 3개 확인

```
PDF 업로드
    │
    ├─ 텍스트 추출 (pdfjs)
    ├─ 핵심 키워드 추출 (Gemini)

              │
              ▼
         뷰어 진입
              │
    ┌─────────┼────────────┐
    │         │            │
  Chat      Quiz      하이라이트
  (질문)  (문제 풀기)  (메모 저장)
    │         │            │
    └─────────┴────────────┘
              │
         대시보드
              │
    ├─ 성취기준별 학습 현황 (취약·이해 중·학습 중)
    └─ AI 학습 요소 분석 (핵심 개념·보완 포인트)
```

## AI 기능 아키텍처

### 업로드 시 (1회)

```
PDF 파일
  → pdfjs로 페이지별 텍스트 추출
  → Gemini: 교과 핵심 키워드 추출
  → NCIC 성취기준 DB와 오프라인 매핑
  → Gemini: 첫 페이지 기반 학습목표 3개 생성
  → Firestore에 저장 (이후 실시간 제공)
```

### 뷰어 사용 중 (실시간)

| 기능 | AI 입력 | AI 출력 |
|------|---------|---------|
| **학습목표** | 첫 페이지 텍스트 + 성취기준 | 학습목표 3개 |
| **Chat** | 현재 페이지 텍스트 + 하이라이트 맥락 + 성취기준 | 소크라테스식 설명 + 꼬리 질문 |
| **페이지 Quiz** | 현재 페이지 텍스트 | 객관식 문항 (1개) |
| **전체 Quiz** | 전체 문서 텍스트 | 객관식 문항 세트 (최대 10개) |
| **O/X 잠금** | 현재 페이지 텍스트 | O/X 참·거짓 문장 + 해설 |

### 대시보드 분석 (수동 실행)

```
퀴즈 기록 + 채팅 질문 + 메모/하이라이트
  → Gemini: 핵심 학습 요소 추출
  → 학습한 개념 / 보완 필요 포인트 / 잘 이해한 부분
```

| 배포 | Vercel (GitHub 연동 자동 배포) |
